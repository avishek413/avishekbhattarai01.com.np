# AVISHEK — 3D Portfolio

A dark, interactive React + Three.js portfolio landing page.

## Stack
- React
- Vite
- React Three Fiber
- Drei
- Three.js
- React Postprocessing

## Run

```bash
npm install
npm run dev
```

## Important
You can replace the navigation content in `src/App.jsx` inside the `NAV` array.

The contact form is front-end only. Connect it to Formspree, a backend API,
or your preferred email service before publishing.

## Main interaction
A = About
V = Video / Visuals
I = Interactive / Innovations
S = Skills
H = Highlights / Honors
E = Experience / Education
K = Knock / Kontak

Hover = glow + label
Click = camera zoom + drawer
Pointer movement = camera parallax
Background = particles + bloom + grain/noise + vignette
